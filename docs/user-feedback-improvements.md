## 使用与边界

双击 `dist/FlowRemoteDemo.exe`，浏览器打开后点击示例入口；也可以注册账号、上传自己的表格。
AI 在线连接需要用户自己的服务商密钥。此次没有使用真实密钥或付费模型；在线成功、失败和返回数据校验由模拟服务测试覆盖，真实界面验证了离线建议和无密钥回退。

后台任务面向当前 Windows 本地单进程应用；请保持应用运行，关闭浏览器不会中断任务。退出应用会暂停，重新启动后恢复持久化步骤。多进程/多机部署不在此次交付范围。
撤销仅在最终完成前开放，旧版本未记录修改前快照的历史决定只能重新审核，不能凭空还原原值。
现有 OA/BI 执行仍是模拟目标；此次新增后台运行针对表格整理任务。

本版本将源码、Windows 程序、对比截图和测试结果一同纳入版本管理；测试数据库、上传缓存及本地会话密钥均由交付目录的 .gitignore 排除。
